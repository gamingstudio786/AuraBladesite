# Aura Blade Static Website

This folder is ready to upload to a GitHub repository for GitHub Pages.

Pages:
- `/` — Home
- `/about` — About Us
- `/privacypolicy` — Privacy Policy
- `/contact` — Contact Us

Contact email: contact@aurablade.site

Recommended GitHub Pages setup:
1. Create a repository for the website.
2. Upload all files from this folder to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, select "Deploy from a branch".
5. Select your main branch and `/ (root)`.
6. Save.
7. If `aurablade.site` is your custom domain, configure the domain's DNS to GitHub Pages and set the Custom domain in GitHub Pages.

Important: The Privacy Policy text is a general template. Before publishing a Google Play app, update it so it accurately reflects the data your specific app, SDKs, analytics, ads, and other third-party services actually collect/process.
