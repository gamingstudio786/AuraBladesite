# Aura Blade — GitHub Pages

Upload the contents of this folder to the root of the `AuraBladesite` repository.

Clean page URLs:
- https://aurablade.site/
- https://aurablade.site/about/
- https://aurablade.site/privacypolicy/
- https://aurablade.site/contact/

GitHub Pages:
Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.

Then add `aurablade.site` under Custom domain and configure your domain DNS for GitHub Pages.
